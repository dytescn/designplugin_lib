# plugin_lib 开发约束

以下变更**必须由人工处理**，禁止在自动化开发中自行修改：

## 数据库结构

- 不能随意修改数据库表结构，包括表名、字段名、字段类型、默认值、约束、索引等。
- 表结构以 `skills/db.md` 和 `setup.json` 为准。
- 需要新增 / 删除 / 调整字段时，先停止改动并交由人工确认，不得自行执行迁移或改写建表语句。

## FFI 接口

- 不能调整现有 FFI 方法名，包括导出符号名及对应的封装名。
- 不能自行新增 FFI 方法。
- 需要新增或重命名接口时，先停止改动并交由人工确认。

## 原则

- 涉及上述两类变更，先说明需求与影响，由人工决定并手动实施。
- 其他实现细节可以正常修改，但不得顺带改动数据库结构与 FFI 接口。
